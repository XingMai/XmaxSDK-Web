## What's New

- 首个 Xmax JavaScript SDK 发布版本，统一安装包为 `@xmaxai/web-sdk`，同时提供框架无关核心入口和可选的 `/react` 子入口。
- 支持摄像头与麦克风采集、实时会话连接、TRTC 音视频传输、生成启停、提示词及参考图更新、断开和资源清理；当前生成模型为 `x2-fast-1080p`。
- 提供 COS 参考图上传能力。X-Lab 示例支持预置参考图、本地预览、上传状态，以及上传前 JPEG 0.9 质量转换。
- 提供启动耗时、本地与远端视频统计、上下行网络质量和 RTT 回调，以及可配置的控制台日志和格式化房间信令日志。
- 内置自训插帧权重，支持远端 WebGPU 2× 插帧、运行时开关及不支持或处理失败时的原视频降级；不改变服务端生成与回传分辨率。
- X-Lab 示例增加分组统计面板、远端音量弹层和插帧开关。进房时关闭 TRTC 自动接收音频，先应用音量再显式订阅，避免默认静音时短暂出声。
- 提供 ESM、CommonJS 和 TypeScript 声明；核心入口不要求安装 React。

## API Changes

- 核心 API 从 `@xmaxai/web-sdk` 导入；React 的 `XmaxVideo`、`XmaxRealtimeVideo` 从 `@xmaxai/web-sdk/react` 导入。
- 使用早期开发包的项目需移除 `@xmax/sdk`、`@xmax/react`，改为安装同一个 `@xmaxai/web-sdk` 包，并更新导入路径：

  ```ts
  import { XmaxClient, XmaxConfiguration, RealtimeConfiguration } from "@xmaxai/web-sdk";
  import { XmaxVideo, XmaxRealtimeVideo } from "@xmaxai/web-sdk/react";
  ```

- 实时 Manager 提供 `setLaunchTimingListener`、`setLocalVideoStatisticsListener`、`setRemoteVideoStatisticsListener` 和 `setNetworkStatisticsListener`。监听器注册后回放当前快照；视频与网络统计在连接清理后清空。
- `RealtimeConfiguration.frameInterpolation` 配置插帧开关与目标帧率上限。运行时可调用 `setFrameInterpolationEnabled`；`isFrameInterpolationEnabled` 旧配置仍兼容，显式 `frameInterpolation.enabled` 优先。
- `XmaxConfiguration.loggerOptions` 控制日志输出，默认不输出；远端音量默认 `0`，通过 `setRemoteAudioVolume(0...1)` 调节。

## Requirements and Known Limitations

- 摄像头、麦克风需要 HTTPS 或 localhost 安全上下文及用户授权。音频播放仍受浏览器自动播放策略影响。
- 插帧依赖 WebGPU、`shader-f16` 和 `requestVideoFrameCallback`；每对源帧最多补一帧，目标最高 60fps，不保证所有设备和分辨率均稳定达到目标帧率。
- 自训模型目前仅有人工初步试用记录，尚未完成原生/WebGPU 全链路一致性验证。真实 TRTC 视频的长时间性能、网络抖动、画面突变与音画同步仍需实机验收；插帧不额外延迟 RTC 音频。
- RTC 统计中的帧率是原始接收流帧率，E2E 是 RTC 提供的估算值，不代表包含生成与客户端插帧的完整端到端延迟。
- 当前 `china` 环境指向 `https://dev.xmaxai.com/open/api/v1`，`global` 环境指向 `https://api.xmax.cloud/open/api/v1`。生产使用前应确认所选环境及 API Key 的适用范围。
- SDK 使用 MIT 许可证；第三方依赖及模型权重的许可和分发授权需分别核验。
- 自动化测试、打包和独立消费端验证不替代摄像头、TRTC、GPU 与音画同步的实机验收。
